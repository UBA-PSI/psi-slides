psi-slides

One Markdown file, four artefacts. This is the tutorial lecture, built from lectures/tutorial/source.md – a lecture that explains the tool by being the tool.

The four views

  • audience.html →

    The projection. Start here. Arrow keys navigate, Space reveals, C toggles collapse, O (the letter, not zero) opens the overview board, ? lists everything.

  • speaker.html →

    The presenter cockpit. Opening it from this link shows the layout, but it will not be in sync with anything – press S inside the audience view to spawn a connected one.

  • print.html →

    The reading document, with a cover and a table of contents. Print it to PDF for students.

  • print-notes.html →

    The same document with every speaker note folded in under its chunk.

All four files are self-contained: CSS, JavaScript, images, the rendered maths and – when the author supplies them – the typefaces are all inlined. Nothing is fetched at run time, and they open just as happily from file:// as from this server.
