psi-slides für die Übung

Eine Markdown-Datei source.md pro Termin ergibt vier HTML-Dateien: Projektion, Cockpit, Skript, Skript mit Notizen. Sie öffnen sich per Doppelklick, ohne Server. Bearbeitet wird nur source.md.

1 · Bauen

Einmalig: Node 22 oder neuer, dann im Ordner psi-slides npm install.

# bauen und bei jedem Speichern neu laden
node ../psi-slides/build.js lectures/ue03/source.md --watch

# vor dem Commit prüfen
node ../psi-slides/lint.js lectures/ue03/source.md

# neues Gerüst anlegen
node ../psi-slides/build.js --new ue04 --into lectures
audience.htmlProjektion für den Beamer
speaker.htmlCockpit: Notizen, Vorschau, Uhr
print.htmlSkript mit dem vollen Text
print-notes.htmlSkript plus Sprechnotizen

2 · Im Raum

  1. audience.html im Browser öffnen, S öffnet das Cockpit in einem zweiten Fenster.
  2. Projektion auf den Beamer ziehen, Cockpit bleibt auf dem Laptop.
  3. W für Vollbild, danach einmal in die Projektion klicken.

Beide Fenster laufen synchron; gesteuert wird aus dem Cockpit. YouTube-Einbettungen spielen nur mit --serve, nicht von file://.

4 · Die Grammatik in sechs Zeilen

# Titel {#id}Teil der Übung, mindestens zwei Folien
## typ: Titel {.breite #id}eine Folie
--- (allein in der Zeile)Schritt: Rest erscheint auf Tastendruck
> note: …Sprechnotiz
::: expand Name … :::Zusatzmaterial, nicht auf der Folie
::: slide … :::genau dieser Block ist die Folie

Typen: free question exercise example definition principle statement figure outline title closing

Breiten: .narrow .standard (Vorgabe) .wide .full

Außerdem: Code in ```-Blöcken, Formeln als $…$ und $$…$$, zwei Spalten mit ::: cols 2, Text neben Bild mit ::: side.

5 · Woran es meistens hängt

  • Text fehlt auf der Folie. Gewollt: Die Projektion zeigt den ersten Satz jedes Absatzes und alles Fette. Wichtiges fett setzen oder ::: slide nehmen; C zeigt den vollen Text.
  • Jede Folie braucht eine eindeutige {#id}. Einmal vergeben, bleibt sie, auch wenn sich die Überschrift ändert.
  • --- ist keine Trennlinie, sondern ein Klick. Für eine Linie *** schreiben.
  • Ein Bild über 2 MB bricht den Build ab. Abhilfe: node ../psi-slides/build.js <source.md> --optimize-images.
  • Folie zu voll? Der Linter zählt die Wörter pro Typ (etwa 80 für question, 350 für exercise) und warnt.
  • Der Build meldet einen Fehler und die alte HTML-Datei bleibt liegen. Erst die Meldung im Terminal lesen, dann im Browser suchen.
